# Replication code — Arka P. Bandyopadhyay

Code for my papers on [SSRN](https://papers.ssrn.com/sol3/cf_dev/AbsByAuth.cfm?per_id=4335011), one folder per paper.

**Confidential data.** Several papers use confidential servicer, loan-level or licensed data. Those data cannot be shared and are not in this repository. For each of those papers the folder contains the code, so reviewers with access to the same data can use it to replicate the results.
