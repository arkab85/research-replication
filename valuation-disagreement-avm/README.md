# Valuation Disagreement, AVM Confidence, and Marketability

Arka P. Bandyopadhyay · Working paper · [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7487939)

## Data availability

This paper uses licensed property listing and automated-valuation data, obtained under confidentiality and licensing terms that do not permit redistribution. **The data cannot be shared, and no data are included in this repository.**

The code in `code/` is the code used to produce the paper's results. Reviewers and researchers with access to the same data can run it to replicate the tables and figures. Scripts read their inputs from the paths set at the top of each file (or in `config.py` where present); point these at your copy of the data.

## Contents

- `code/` — analysis code (Python). Notebook outputs have been cleared.
