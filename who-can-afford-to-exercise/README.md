# Who Can Afford to Exercise? Balance Sheet Capacity and Mortgage Buyout Decisions in the Pandemic Forbearance Wave

Arka P. Bandyopadhyay · Under review · [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7427960)

## Data availability

This paper uses Ginnie Mae loan-level servicing and buyout records, obtained under confidentiality and licensing terms that do not permit redistribution. **The data cannot be shared, and no data are included in this repository.**

The code in `code/` is the code used to produce the paper's results. Reviewers and researchers with access to the same data can run it to replicate the tables and figures. Scripts read their inputs from the paths set at the top of each file (or in `config.py` where present); point these at your copy of the data.

## Contents

- `code/` — analysis code (Python). Notebook outputs have been cleared.
